# 项目展示与简历

## 能演示的场景

1. 打开示例，筛选 ERROR，搜索 timeout。
2. 选择匹配行，解释为何上下文中能看到被过滤的相邻日志。
3. 添加书签，重置筛选后跳转书签，重开同一文件验证持久化。
4. 导出筛选结果，展示错误正则和源文件保护。
5. 打开自己生成的大文件，演示搜索进度、取消和内存占用。
6. 修改源文件，展示索引失效与自动重载。

## 简历描述模板

基于 C++17、Qt 6 Widgets、MSVC 和 CMake 开发 Windows 日志分析工具；设计行偏移索引和按需读取模型，实现级别过滤、可取消的异步搜索、原始上下文查看、书签持久化与原子导出。通过 Qt Test 验证块边界、UTF-8、源文件变化和后台任务生命周期。

性能描述请从 `benchmark.md` 取真实数据，注明文件大小、行数、运行环境和测量范围。不要把 CLI 索引时间写成 GUI 首屏时间，也不要把一次热缓存结果写成跨设备性能承诺。

## 面试准备

- 画出模型、索引、视图与后台任务之间的数据流。
- 解释偏移索引相对全文载入的内存取舍，以及短行过多时的索引开销。
- 展示 generation token 如何阻止过期结果覆盖新搜索。
- 解释 QObject 线程归属，为什么模型更新必须在 GUI 线程。
- 说明单行限制、预览截断、取消粒度和文件版本校验的边界。
- 选择一个后续迭代独立完成，保存设计记录、提交历史和前后测量结果。

这个初始版本由 Codex 协助实现。用于个人项目展示时，应理解、验证并实际改进代码；面试中如实说明自己负责的部分与工具协助范围。
